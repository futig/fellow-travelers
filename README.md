# fellow-travelers

Сервис поиска попутчиков: помогает участникам мероприятия встретиться в аэропорту и вместе доехать на такси до места назначения.

Подробное описание, сценарии и открытые вопросы — в [docs/Capabilities_Poputchiki.md](docs/Capabilities_Poputchiki.md).

## Разработка

Нужны: Python 3.12, Node.js ≥ 20, Docker (Postgres поднимается в контейнере на порту 5434), GNU make.
Команды — из корня репозитория (Linux/macOS).

```bash
make dev-setup   # один раз: venv и зависимости, backend/.env, БД, миграции, аэропорты, тестовые пользователи
make dev         # каждый раз: бэкенд (:8000) и фронт (:5173) вместе, Ctrl+C останавливает оба
```

Открой http://localhost:5173. Telegram и бот не нужны: внизу экрана — плашка «Dev: пользователь» с тестовыми
пользователями (у всех уже есть телефон, у одного нет @username). Выбор свой в каждой вкладке, поэтому подбор
попутчиков проверяется в двух вкладках:

1. Вкладка 1, «Иван»: «Создать группу» → «Рейсы группы» → добавить рейс → «Приглашение» → скопировать код.
2. Вкладка 2, «Мария»: «Ввести код приглашения» → вступить → заполнить заявку на тот же рейс.
3. Вкладка 1: «Вступить как участник» → заявка на тот же рейс → оба видят друг друга в «Моей поездке».
4. Отметки «Я на месте» / «Уехал» появляются за час до прилёта — для проверки поставь рейсу прилёт на ближайший час.

Остальные команды — `make help`:

| Команда | Что делает |
| --- | --- |
| `make dev-users` | Пересоздать initData тестовых пользователей (если API отвечает 401 — истёк срок, по умолчанию неделя). `DEV_USERS=5 make dev-users` — до 5 пользователей |
| `make backend` / `make frontend` | Запустить только одну часть |
| `make db` / `make db-stop` | Поднять / остановить Postgres (данные сохраняются в volume) |
| `make migrate`, `make seed` | Миграции, справочник аэропортов |
| `make test`, `make check` | Тесты; все проверки бэкенда и фронта (как перед коммитом) |

Как это устроено: бэкенд принимает только initData, подписанную `BOT_TOKEN`. В dev токен — любая строка
(`dev-token` в `backend/.env`), а `make dev-users` (`python -m app.dev.users`) создаёт пользователей в БД и подписывает
для них initData. Результат пишется в `frontend/.env.development.local` (не коммитится); прод-сборка этот код не содержит.

Проверка внутри настоящего Telegram (бот, туннель, BotFather) — в [frontend/README.md](frontend/README.md#запуск-внутри-telegram).
